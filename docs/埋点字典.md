> 版本：v1　最后更新：2026-06-07

> 状态说明：✅ 已实现（本版本字典内事件均已接入代码）

---

## 一、概述

- **上报方式**：自建上报接口 `POST /track/report`（批量）。当前 `track.js` 中 `USE_MOCK=true`，仅 `console` 输出；接后端置 `false` 并填 `REPORT_URL`。
- **采集策略**：页面 PV/停留时长全局自动采集；关键业务行为手动埋点。
- **可靠性**：满 10 条或每 5s 批量上报；失败写本地缓存，下次启动补传。
- **合规**：采集前需用户同意隐私协议；仅上报 id，不上报明文手机号/姓名等 PII。

---

## 二、命名规范

- **事件名**：`模块_对象_动作`，小写蛇形。例：`home_quick_click`、`report_detail_view`。
- **参数名**：小写蛇形。例：`student_id`、`report_id`、`success`。
- **布尔参数**：统一用 `true/false`。
- **页面路径**：由 SDK 自动写入 `page` 字段（如 `/pages/index/index`），事件参数中不重复携带。

---

## 三、公共属性（每条事件自动附加）

| 字段 | 含义 | 来源 | 备注 |
|---|---|---|---|
| `event` | 事件名 | track() | |
| `ts` | 毫秒时间戳 | track() | |
| `page` | 当前页面路径 | SDK 自动 | |
| `session_id` | 会话 ID | 每次启动生成 | |
| `user_id` | 用户 ID | 登录后 | 未登录为空 |
| `role` | 角色 | 登录后 | 固定 `parent` |
| `student_id` | 当前学生学号 | 首页加载 | 多孩切换时更新 |
| `scene` | 微信场景值 | onLaunch options | 来源分析 |
| `network` | 网络类型 | 上报时取 | wifi/4g/... |
| `brand` / `model` | 机型 | 设备信息 | |
| `app_version` / `sdk_version` | 版本 | 基础库信息 | |

## 六、上报契约

```
POST /track/report
Content-Type: application/json

{
  "common": {
    "session_id": "string",
    "user_id": "string",
    "role": "parent",
    "student_id": "string",
    "scene": 1001,
    "network": "wifi",
    "brand": "iPhone",
    "model": "iPhone 14",
    "app_version": "1.0.0",
    "sdk_version": "3.0.0"
  },
  "events": [
    { "event": "home_quick_click", "ts": 1730000000000, "page": "/pages/index/index", "params": { "key": "score" } }
  ]
}

响应： { "code": 0 }
```

> 建议后端：按 `event` 入明细表，`common` 冗余进每条或单独会话表；保留原始 JSON 便于回溯。

## 七、接入与维护

- **新增事件**：在对应页面 `track.track('事件名', { 参数 })`；同步更新本字典并把状态置 ✅。
- **改 USE_MOCK**：`utils/track.js` 顶部开关；本地调试在开发者工具 Console 搜 `[track]`。
- **隐私开关（可选）**：如需在「账户设置」提供统计开关，未开启时仅上报匿名 `app_launch/page_view`。

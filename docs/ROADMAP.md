# 「骑字」产品路线图

## 愿景

把城市变成纸、车轮变成笔。让每一次骑行都成为一件可分享、可收藏、可挑战的作品。

## 用户画像

1. **晒图型骑友**（核心）：周末骑车，发朋友圈是骑行仪式的一部分。要的是"好看 + 有梗"。
2. **仪式纪念型**：生日、纪念日、表白、跨年（骑个 2027）。低频但传播力最强。
3. **硬核码表党**：佳明/行者用户，看重路线质量与 GPX，是社区里的内容生产者。
4. **收集控**：被字母收集册勾住，想把 26 个字母骑完。

## 北极星指标

**每周生成并保存的海报数**（代表完整闭环跑通且产生传播素材）。
辅助：路线创建数、骑行完成率（开始骑/完成骑）、海报保存率、分享回流率。

## 已完成（V1.0 提审版）

- 设计：A-Z/0-9/汉字/♥★，灵感模板，缩放/旋转/拖移，贴合道路，锚点微调，
  **字形还原度评分**，**自动找位置**（探针式快速评估），路线缩略图
- 骑行：沿线导航（转向/偏航/推行提示 + 震动 + TTS 语音），GPS 三重过滤，
  暂停分段，完成度
- 成果：**还原度得分**（轨迹 vs 计划，印上海报），20+1 种海报主题（分类选择 +
  自定义照片背景），骑行金句
- 增长钩子：字母收集册、累计统计、路线广场、复制去修改、GPX 导出（WGS-84）、
  好友分享 + 朋友圈分享（onShareTimeline）

## V1.1 — 上线后第一个月（打磨与数据）

- [ ] 接入小程序数据分析，埋点核心漏斗（输入→生成→贴路→保存→骑行→海报→保存相册）
- [ ] 海报加小程序码（后端 getwxacodeunlimit，云函数即可），分享回流闭环
- [ ] 路线广场按城市筛选（保存路线时记录城市，逆地理编码一次即可）
- [ ] 大图片压缩（wx.compressImage）防自定义照片主题内存峰值
- [ ] 真机回归清单制度化（后台定位、保存相册、TTS、GPX 分享）

## V1.2 — 社交与挑战（留存）

- [ ] **挑战赛**：官方周挑战（如"本周骑个 ♥"），完成者进展示墙；运营成本低、
  传播性强，是最适合本产品的活动形态
- [ ] 路线点赞/骑过人数（同一路线被多少人骑过——"经典路线"沉淀）
- [ ] 还原度排行榜（按路线/按城市），给硬核用户竞技场
- [ ] 收集册分享卡（"我已点亮 18/26"，直接是传播素材）

## V2 — 创作工具升级

- [ ] 多行排版（名字竖排/两行）、字间距调节、镜像
- [ ] 自由画板：手指在地图上画任意图案再贴路（猫、自行车、生日蛋糕轮廓）
- [ ] 团队共骑：多人分工骑不同笔画，轨迹合成一个大字（技术上只需合并多条 ride）
- [ ] 路网密度热力提示：预判哪些区域适合骑字（需要后端预处理 OSM 数据）

## 明确不做

- 不做通用骑行记录 App（速度/功率/心率训练分析）——与行者/Strava 正面竞争无胜算，
  保持"骑字"的单点锋利
- 不做积分商城/实物激励——收集册和还原度的内在动机更健康
- V2 前不做自建后端——云开发足够，保持零运维

## 技术债备忘

- selftest 已覆盖全部纯函数模块（90+ 用例），新模块必须带用例
- qqmap key 建议正式运营时迁移云函数代理（防盗用 + 统一缓存）
- hanzi-writer-data 若 CDN 不稳，可把 GB2312 常用 3500 字打包进云存储自托管

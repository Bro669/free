```
登录（一键授权 / 手机验证码）
├─ 首页（问候 Banner · 快捷入口宫格 · 消息中心 · 多孩切换 · 登录/未登录态）
│   ├─ 校园简介（学校简介 / 学校文化 Tab）
│   ├─ 消息中心（全部 / 已读 · 卡片列表 · 空态）
│   ├─ 成绩查询（柱状 / 折线图 · 学期 / 科目筛选）
│   ├─ 测评报告（报告列表 · 生成中 · 空态）
│   ├─ 教师信息（班主任 + 任课教师卡片）
│   ├─ 家长课堂（文章列表 / 文章详情）
│   └─ 成长档案（生涯成长档案卡片）
└─ 我的
    ├─ 个人信息（表单编辑 · 选择器 / 抽屉）
    ├─ 添加生涯顾问（企业微信二维码）

```

架构清晰、层级合理（3 级以内），符合家长用户「轻量查询」的使用场景。

## 四、UI 视觉风格评估

**整体定位：暖橙色调 + 卡通吉祥物 + 卡片化的「亲和型教育产品」。**

- **主色**：暖橙（活力、阳光，契合教育亲子场景），辅以白底 + 浅灰背景，对比舒适。
- **吉祥物**：橙色机器人 IP（戴护目镜），用于 App 图标、空态、反馈成功页，品牌记忆点强 ✅。
- **布局**：圆角卡片 + 柔和阴影 + 大留白，现代小程序主流风格。
- **导航**：顶部遵循微信小程序规范（返回 + 标题 + 胶囊），底部 Tab 栏，符合用户习惯。
- **数据可视化**：成绩 / 成长档案用品牌化 Banner + 图表，视觉档次较高。
- **空态设计**：消息中心、测评报告均有定制吉祥物空态插画，完成度高 ✅。

整体高保真完成度好，视觉语言统一，可直接进入开发还原。

## 六、问题与改进建议

> 按优先级排列，🔴 为定稿 / 上线前必须处理的阻塞型问题。

### 🔴 高优先级（阻塞型）

1. **品牌名称三处不一致**
   - 文档标题：**和铖**家长端
   - UI 界面：**一支橙**家长端（登录 / 首页）
   - 关于我们：**和铖教育**
   - 且需求总述明确标注「小程序名称：**待确认**」。
   - → 需尽快统一品牌主体与小程序正式名称，否则提审与上线受阻。

2. **大量占位文案未确认（Lorem ipsum）**
   - 关于我们、用户协议、隐私协议正文仍为英文假字，联系方式为 `400-888-8888 / 8888888@gmail.com` 占位。
   - → **隐私协议 / 用户协议是微信小程序提审强制项**，必须替换为正式合规文案，否则审核驳回。

3. **App 图标 / 默认头像未定稿**
   - 图标多尺寸标注「待确认」；教师信息处「教师默认头像（UI 设计）」未给出。
   - → 需补齐图标各尺寸切图与默认头像规范。

### 🟡 中优先级（体验 / 规范）

4. **底部 Tab 中间项语义不清**：首页底部导航中间图标含义不明确，建议明确 Tab 数量与各自落地页。
5. **多孩切换交互细节**：首页有单孩 / 多孩两套状态，但切换入口的反馈（当前选中态、切换动效）建议补充标注。
6. **提审白名单**：文档已注明「提审需一个白名单手机号用于审核」——建议提前与开发约定测试账号，避免临期遗漏。
7. **前后台字段一致性**：后台「批量留言 / 家长绑定、家长信息字段表」与前端字段需做一次一致性核对（尤其个人信息表单）。

### 🟢 低优先级（打磨）

8. 部分页面（账户设置、协议页）UI 偏朴素，与首页 / 成绩页的高视觉档次略有落差，可适度统一精致度。
9. 测评报告 / 成绩查询的筛选器（学期、科目）建议明确无数据 / 部分数据时的展示规则。

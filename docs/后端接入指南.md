## 0. 前置准备（先和后端/运维确认）

- **网关域名**：测试 / 生产，必须 HTTPS（本地可用 `http://localhost` + 开发者工具关校验）。
- **统一响应结构**：如 `{ code, message, data }`，成功码是多少。
- **鉴权**：token 放哪个 header、是否带 `Bearer ` 前缀、失效码是多少。
- **登录流程**：`wx.login` 的 `code` 交哪个接口换 token；手机号登录方式。
- **文件上传接口**：path、字段名、返回结构。
- **分页规范**：参数名与 `total` 字段名。
- **枚举字典**：单位类型 / 年收入 / 工作年限等下拉，前端固定还是后端下发。

## 2. 字段不一致怎么办（适配层，页面零改）

后端字段名与前端契约对不上时，**不要改页面**，在 `request.js` 的 `adapters` 里集中转换：

```js
const adapters = {
  // 后端 -> 前端
  '/home/index': (d) => ({
    notice: d.noticeText,
    quickEntries: d.entries,
    archiveProgress: d.archiveRate,
    student: d.studentInfo
  }),
  '/score/list': (d) => ({
    ...d,
    subjects: d.subjectList.map((s) => ({
      name: s.subjectName, score: s.score, full: s.fullScore, rank: s.rank, trend: s.history
    }))
  })
};
```
`request()` 会在 resolve 前自动套用 `adapters[url]`。

## 3. 登录链路（小程序特有）

- **微信一键登录**：`auth.getWxCode()` 已在登录页调用，拿到 `code` 随 `/login/wechat` 提交，后端用 code 换 `openid/token` 返回 `{ token, userInfo }`。
- **手机号**：若用微信手机号授权，需把「微信一键登录」按钮改为
  `<button open-type="getPhoneNumber" bindgetphonenumber="...">`，拿到 `code/加密数据` 交后端解密；当前实现为「手机号 + 短信验证码」方式（`/login/sendCode` + `/login/sms`）。
- 登录成功调用 `app.setLogin(token, userInfo)`（已接），token 落本地缓存，后续请求自动带上。
- **401 失效**：`request.js` 自动清登录态并跳登录页，无需各页处理。

## 5. 微信平台配置

- **服务器域名**：微信公众平台 → 开发管理 → 开发设置 → 服务器域名，加入 `request` 合法域名与 `uploadFile` 合法域名（均需 HTTPS、ICP 备案）。
- **本地联调**：开发者工具 → 详情 → 本地设置 → 勾「不校验合法域名…」，即可连 `http://localhost`。
- **跨域**：小程序 `wx.request` 不走浏览器 CORS，后端无需配 CORS。
- **AppID**：`project.config.json` 改成正式 AppID。

## 8. 常见问题

- **请求 403/域名不合法**：检查合法域名配置或本地关校验。
- **拿不到 data**：核对 `SUCCESS_CODE` 与 `DATA_FIELD`。
- **登录后接口仍 401**：确认 `app.setLogin` 已存 token，且 `TOKEN_HEADER/TOKEN_PREFIX` 与后端一致。
- **上传失败**：核对 `UPLOAD_PATH`、字段名 `file`、返回结构取值。

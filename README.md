# 骑字 🚴 — 在城市里骑出你的名字

一个微信小程序：输入字母/数字（如名字缩写、纪念年份），程序把字形投影到城市地图上，
沿真实道路规划出可骑行的路线；骑完后用 GPS 轨迹生成海报，保存相册发朋友圈。

## 玩法闭环

1. **设计**：输入文字（A-Z / 0-9 / **汉字**，最多 6 字符，汉字建议 1-2 个）→ 字形轮廓出现在地图上 → 拖动 / 缩放（字高 500m–5km）/ 旋转对齐路网 → 「贴合道路」沿真实道路重新规划 → 点锚点微调 → 保存（可公开到广场）
2. **骑行**：内置沿线导航——转向提示横幅（「120m 后左转」+ 震动）、偏航报警（偏离 45m 红色横幅 + 长震动）、推行衔接段提示、完成度百分比、地图自动跟随；GPS 实时记录绿色轨迹（支持暂停/继续、锁屏后台记录）
3. **纪念**：自动生成轨迹海报（骑出的「字」+ 距离/时长/均速/日期 + 底部**骑行金句**
   可一键换一句），**十种风格**一键切换——经典 / 多巴胺（糖果渐变+彩纸屑）/
   蒸汽波（紫粉渐变+CRT 扫描线）/ 像素（8-bit 方块轨迹）/ 酸性（荧光绿+噪点）/
   国潮（朱红鎏金）/ 沙画（沙粒纹理+沟槽轨迹）/ 霓虹（星空+发光线）/
   蓝图（网格制图）/ 极简，保存相册发朋友圈；预览见 docs/poster-preview.png
4. **广场**：浏览别人公开的字形路线，一键「复制去修改」搬到自己城市

## 跑起来（必做配置）

1. **小程序账号**：注册小程序，把 AppID 填入 `project.config.json` 的 `appid`
   （类目建议选 **体育-运动健身**，后台定位审核需要）。
2. **云开发**：微信开发者工具 → 云开发 → 创建环境，环境 ID 填入 `miniprogram/config.js`
   的 `CLOUD_ENV`；右键 `cloudfunctions/login` 与 `cloudfunctions/getHanzi` →
   上传并部署（云端安装依赖）。getHanzi 负责汉字笔画数据（来源 jsdelivr/unpkg 的
   hanzi-writer-data），不部署则只支持 A-Z/0-9。
3. **云数据库**：在云开发控制台创建集合 `routes` 和 `rides`，权限设置：
   - `routes` → 自定义安全规则：
     ```json
     {
       "read": "doc.isPublic == true || doc._openid == auth.openid",
       "write": "doc._openid == auth.openid"
     }
     ```
   - `rides` → 「仅创建者可读写」
4. **腾讯位置服务**：到 https://lbs.qq.com/ 创建应用与 Key（勾选 WebServiceAPI），
   填入 `miniprogram/config.js` 的 `TENCENT_MAP_KEY`；小程序后台「开发-服务器域名」
   添加 request 合法域名 `https://apis.map.qq.com`。
   未配置 Key 时贴路自动降级为直线虚线，其余功能可用。
5. **隐私设置**（上线必做）：小程序后台「设置-服务内容声明-用户隐私保护指引」
   声明收集 **位置信息**，否则定位接口直接报错。
6. **语音播报插件**（可选）：小程序后台「设置-第三方设置-插件管理」搜索添加
   **微信同声传译**（免费）。不添加则编译时删除 `app.json` 的 `plugins` 块，
   语音自动降级关闭，导航横幅/震动不受影响。

## 开发者工具验证清单

- 设计页：输入 `AB` → 地图出现字形折线；拖动字高/旋转滑杆实时变形；开「移动文字」拖地图字随动
- 贴路：Network 面板可见对 `apis.map.qq.com` 的串行请求；填错 Key 验证降级为橙色虚线
- 微调：点一个锚点 → 出现十字准星 → 拖地图 → 确定，仅重发相邻 2 段请求
- 骑行：「模拟位置-移动轨迹」回放路径验证轨迹/距离/均速；**后台定位与锁屏需真机预览验证**
- 海报：结束骑行后自动生成；保存相册需真机
- 纯函数回归：`node scripts/selftest.js`（无需开发者工具）

## 关于导航

字形路线**不能调起腾讯/高德等外部导航**——外部导航只接受起终点，会按最短路径重新
规划，字形就毁了。所以导航是内置的「沿线引导」：

- 把既定路线当作唯一真理，每个定位点投影到路线折线上做轨迹匹配
- 字母路线经常**沿同一条路折返**（如 A 的横线、E 的中横），匹配带「进度窗口 +
  航向罚分」：只在上次进度附近搜索，且候选路段方向与骑行方向相反时加罚分，
  保证折返时进度不回跳（`scripts/selftest.js` 中有折返回归用例）
- 拐点在路线加载时预先提取（前后 15m 方向夹角 ≥30°，相邻 25m 内聚类取最大角），
  骑近 800m 显示「xxm 后左转/右转/掉头」，60m 内震动提醒
- 偏航 45m 报警（长震动 + 红色横幅），回到 30m 内解除（滞回防抖）
- **语音播报**已内置（utils/tts.js，基于官方免费的「微信同声传译」插件）：
  转弯两档播报（200m「两百米后左转」/ 60m「前方左转」）、偏航进出、推行切换、
  完成提示，各事件只播一次；骑行页右上可开关；iOS 静音键下仍出声（导航场景）。
  启用需要两步：① 小程序后台「设置-第三方设置-插件管理」添加「微信同声传译」
  （搜索 WechatSI，免费，秒过）；② 保持 app.json 中 plugins 声明即可。
  未添加插件时编译会报「插件未授权」——临时删除 app.json 的 plugins 块即可，
  代码会自动静默降级（无语音，其余导航功能不受影响）

## 已知限制

- 字形还原度取决于路网密度：方格路网城区效果最佳，水域/高架/单行道附近会变形，
  善用「旋转」把笔画对齐主干道方向
- 个人开发者的路线规划 API 配额约 1 万次/日、5 QPS（已做限流+缓存+降级），
  正式运营建议企业认证提额或加云函数代理
- 后台定位需用户在弹窗中主动选「使用小程序期间和离开后」；未选则降级前台记录（保持亮屏）
- GPS 漂移在高楼区不可避免，已做精度/速度/抖动三重过滤，建议在开阔路段骑
- 汉字已支持（hanzi-writer-data 覆盖 GB2312 常用字～9000 字）；汉字笔画多
  （平均 8-12 笔/字），衔接推行段相应变多，建议一次骑 1-2 个字、字高 ≥2km

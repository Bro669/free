# 家长端微信小程序

教育 / 升学方向的家长端微信小程序（原生开发，无构建步骤）。后端接口当前为 mock 占位，统一封装，可一键切换真实后端。

## 目录

```
free/
├── miniprogram/   小程序工程（微信开发者工具导入此目录）
└── docs/          设计与对接文档
```

## 快速开始

1. 微信开发者工具 → 导入项目 → 选择 `miniprogram/` 目录。
2. `project.config.json` 的 `appid` 为测试号，正式开发替换为自己的 AppID。
3. 直接编译预览（mock 模式开箱即用）。

详见 [`miniprogram/README.md`](miniprogram/README.md)。

## 技术要点

- **原生小程序**：一页一目录、四件套同名，符合微信项目结构规范。
- **请求层**（`utils/request.js`）：mock 开关、响应结构可配、token / 401、字段适配层、文件上传。
- **埋点**（`utils/track.js`）：全局自动 PV + 业务事件，批量上报、失败补传。
- **图表**（`utils/chart.js`）：Canvas 2D 柱状 / 折线 / 雷达。
- 视觉：暖橙主色 `#FF8C28`，设计 Token 定义于 `app.wxss`。
